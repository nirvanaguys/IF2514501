# Praktikum Desain Web

Repositori ini berisi kumpulan tugas dan latihan praktikum untuk mata kuliah Desain Web (Semester 5). Proyek di dalamnya mencakup implementasi dasar web, styling, interaktivitas, serta penggunaan library frontend.

## Struktur Direktori

- **1/**
  - Implementasi dasar struktur halaman web menggunakan HTML dan CSS murni.
  - Berisi file `main.html` dan `style.css`.

- **2/**
  - Latihan desain web modern dan interaktivitas halaman.
  - Menggunakan Tailwind CSS untuk styling utilitas dan JavaScript dasar.
  - Berisi file `Soal Praktikum Tailwind  Javascript.html`.

- **3/**
  - Latihan manipulasi DOM dan efek interaktif pada antarmuka web.
  - Menggunakan library jQuery.
  - Berisi file `Soal Praktikum jQuery.html`.

## Cara Menjalankan

Buka file HTML yang ingin dilihat langsung menggunakan peramban web (browser) seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge, atau gunakan ekstensi live server di teks editor (seperti VS Code).
